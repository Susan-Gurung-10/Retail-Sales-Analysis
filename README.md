# Retail Sales Analysis
Exploratory data analysis of retail transactions using Python, covering data cleaning, revenue by product category and monthly sales trends.

## Objective
Understand which product categories drive revenue and how sales change over time.

## Dataset
- Retail transaction data from January 2023 to January 2024.
- Columns include: Date, Product Category, Age, Quantity, Price per Unit, Total Amount.
  
## Tools Used
- Python(Pandas, Numpy)
- Data Visualization(Matplotlib, Seaborn)
- Jupyter Notebook
